# Переводы и теги head

## Переводы

```php
// lang/ru.php
return [
    'cart' => [
        'title' => 'Корзина',
        'items' => '{n} товар|{n} товара|{n} товаров',
    ],
];

// lang/en.php
return [
    'cart' => [
        'title' => 'Cart',
        'items' => '{n} item|{n} items',
    ],
];
```

В шаблоне и в PHP одинаково:

```html
<h2>{{ t('cart.title') }}</h2>
<p>{{ t('cart.items', {n: len(cart)}) }}</p>
```

```php
t('cart.items', ['n' => 3]);   // «3 товара»
```

- Формы числа разделяются через `|`: для русского и других славянских три формы (1 товар, 2 товара, 5 товаров), для остальных языков две. Число передаётся параметром `n` или `count`.
- `{имя}` подставляет параметр.
- Если перевода нет, берётся язык по умолчанию, а если нет и там, выводится сам ключ.
- В браузере `t()` работает без запросов: словарь страницы приходит вместе с ней.

Язык определяется по cookie `locale`, затем по заголовку `Accept-Language`, затем берётся `'i18n' => ['default' => 'ru']`. Список языков задаёт `'i18n' => ['locales' => ['ru', 'en']]`. Сменить язык можно в действии:

```php
#[Action]
public function use(string $lang): void
{
    I18n::setLocale($lang);
    redirect('/');      // страница загрузится целиком — layout тоже переведётся
}
```

## Теги head

```php
<?php
$title = 'Каталог';
Rig\Head::set(description: 'Кофе, чай и посуда', image: '/img/catalog.jpg');
Rig\Head::set(robots: false);          // noindex, nofollow — для личных страниц
Rig\Head::meta('author', 'rig');
Rig\Head::link('alternate', '/en/catalog', ['hreflang' => 'en']);
```

В layout теги выводит `<?= Rig\Page::head() ?>`: `<title>`, description, canonical, Open Graph (`og:title`, `og:description`, `og:image`, `og:url`, `og:site_name`) и Twitter-карточку. Их содержимое берётся из заголовка, описания и картинки. Адреса становятся полными по `APP_URL`. При переходах без перезагрузки теги меняются сами.

Значения по умолчанию задаются в `config.php`: `'head' => ['title' => …, 'description' => …, 'image' => …, 'site' => …]`.
