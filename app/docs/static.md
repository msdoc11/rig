# Статический сайт

```bash
rig generate              # собирает сайт в dist/
rig generate --out=build
```

Каждая страница `app/pages` становится файлом `dist/{адрес}/index.html`; рядом кладутся содержимое `public/`, рантайм `_rig/runtime.js`, модули `app/js` и `404.html`. Папку можно выложить на любой статический хостинг: GitHub Pages, Netlify, S3, nginx без PHP.

## Динамические страницы

Для `pages/docs/[slug].php` нужен список значений в файле рядом:

```php
// pages/docs/[slug].paths.php
return ['start', 'components', 'state'];
```

## Что работает в статике

- Всё, что считается при сборке: данные из базы, Markdown, переводы на момент сборки.
- Компоненты, которые живут в браузере: `#[Client]`, `#[Shared]`, `#[Computed('выражение')]`, анимации, `r-js`.
- Переходы между страницами, только обычной загрузкой, без перехвата ссылок.

Не работает то, чему нужен сервер: действия `#[Action]`, `mount()` при загрузке, `#[Lazy]`, серверные `#[Computed]`, вход, API. `rig generate` предупредит, на каких страницах такие компоненты. Страницы с middleware (только для вошедших) пропускаются.
