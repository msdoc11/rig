# Состояние

Публичные свойства компонента составляют его состояние. Где свойство живёт и как обновляется, задаёт атрибут.

| Объявление | Где живёт | Когда обновляется |
|---|---|---|
| `public int $x` | PHP, хранится на странице в подписанном снимке | изменения из `r-model` уходят на сервер со следующим действием |
| `#[Locked]` | PHP | браузер не может прислать значение; локально менять можно |
| `#[Prop]` | задаёт родитель | при каждой перерисовке родителя |
| `#[Client]` | только браузер | сразу, без запросов |
| `#[Computed('expr')]` | вычисляется | сразу на сервере и в браузере |
| `#[Computed]` на методе | вычисляет PHP | после ответа сервера |

## Серверное состояние

Обычное публичное свойство живёт в PHP. Между запросами его значение хранится на странице в снимке, подписанном ключом приложения: подделать его нельзя. С каждым действием браузер присылает снимок обратно, PHP восстанавливает компонент, выполняет действие и возвращает новое состояние.

## Только в браузере: #[Client]

Подходит для того, что серверу знать не нужно: вкладок, модальных окон, фильтров по уже загруженным данным.

```php
#[Client]
public string $filter = 'all';
```

```html
<button @click="filter = 'done'" :class="{active: filter == 'done'}">Готовые</button>
```

Переключение не делает ни одного запроса.

## Вычисляемые значения

`#[Computed('выражение')]` на свойстве считается и в PHP, и в браузере, поэтому обновляется сразу, вместе с optimistic-изменениями:

```php
#[Computed("where(todos, 'done', false) | len")]
public int $left;
```

`#[Computed]` на методе без параметров считает только сервер: удобно для запросов в БД и сложной логики. Значение обновится после ответа сервера.

По computed-списку можно делать `r-for` и менять его элементы через `r-model`:

```php
#[Computed("where(todos, 'done', false)")]
public array $open;
```

```html
<li r-for="t in open" :key="t.id">
  <input type="checkbox" r-model="t.done"> {{ t.title }}
</li>
```

`where()`, `whereNot()`, `slice()` и другие функции-фильтры возвращают те же элементы, что лежат в исходном списке. Поэтому изменение `t.done` попадает в `todos`, и на сервер со следующим действием уходит `todos`. Если `todos` помечен `#[Locked]`, изменение останется в браузере, а сохранять его нужно действием.

## Защита данных: #[Locked]

Так помечают то, что браузер не должен подменять: список из БД, идентификаторы, роли.

```php
#[Locked]
public array $todos = [];
```

Браузер не сможет прислать новое значение. Локально, в шаблоне, менять его можно, например чтобы показать изменение до ответа сервера.

## Ограничения

В состоянии допустимы только скаляры и массивы. Модели и даты преобразуйте в массив.
