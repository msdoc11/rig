# Свой JavaScript

Приложение на rig пишется без JS, но для графиков, карт и редакторов нужны сторонние библиотеки. Для них есть `r-js`: элемент, содержимым которого управляет ваш модуль.

```html
<div class="chart" r-js="sparkline" r-props="{points: points}" @pick="picked = $event.detail">
  График загружается…
</div>
```

```js
// app/js/sparkline.js
export function mount(el, props, ctx) {
  const canvas = document.createElement('canvas');
  el.replaceChildren(canvas);
  draw(canvas, props.points);
  canvas.onclick = () => ctx.emit('pick', props.points.at(-1));

  return {
    update(next) { draw(canvas, next.points); },   // свойства поменялись
    unmount() { /* убрать обработчики, таймеры */ },
  };
}
```

## Как это работает

- Модуль загружается из `app/js/{имя}.js` как ES-модуль (`import`), один раз, когда элемент появляется на странице. В режиме разработки правка модуля перезагружает страницу.
- `r-props` содержит выражение шаблона. Когда его значение меняется (например, после действия на сервере), вызывается `update()`. Содержимое элемента rig больше не трогает.
- Когда элемент убирают со страницы, вызывается `unmount()`.
- Содержимое элемента в шаблоне служит запасным текстом, пока модуль грузится.

## ctx

| | Что делает |
|---|---|
| `ctx.emit('событие', данные)` | событие для `@событие` на элементе, данные приходят в `$event.detail` |
| `ctx.call('действие', …аргументы)` | вызвать `#[Action]` компонента |
| `ctx.set('свойство', значение)` | поменять свойство компонента |
| `ctx.get('свойство')` | прочитать свойство |
| `ctx.el` | сам элемент |

Сторонние библиотеки подключайте внутри модуля: `import Chart from 'https://cdn.jsdelivr.net/npm/chart.js/+esm'` или файлом из `public/`.
